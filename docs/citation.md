# Citation

If SMINT contributes to your research, please cite the paper that describes
it:

> Kriel J, Moffet JJD, Lu T, Fatunla OE, Narayana VK, Valkovic A, Maluenda A,
> McConville MJ, Tsui E, Whittle JR, Best SA, Freytag S. **An integrative
> spatial multi-omic workflow for unified analysis of tumor tissue.**
> *Cell Reports Methods* 6(2), 101306 (2026).
> [doi:10.1016/j.crmeth.2026.101306](https://doi.org/10.1016/j.crmeth.2026.101306)
> · [Full text](https://www.cell.com/cell-reports-methods/fulltext/S2667-2375(26)00006-8)

The same citation is in
[`CITATION.cff`](https://github.com/JurgenKriel/SMINT/blob/main/CITATION.cff),
so GitHub's **Cite this repository** button (in the sidebar of the repository
page) gives it in APA and BibTeX.

    ```bibtex
      author  = {Kriel, Jurgen and Moffet, Joel J. D. and Lu, Tianyao and

    }
    ```

=== "APA"

    Kriel, J., Moffet, J. J. D., Lu, T., Fatunla, O. E., Narayana, V. K.,
    Valkovic, A., Maluenda, A., McConville, M. J., Tsui, E., Whittle, J. R.,
    Best, S. A., & Freytag, S. (2026). An integrative spatial multi-omic
    workflow for unified analysis of tumor tissue. *Cell Reports Methods*,
    *6*(2), 101306. https://doi.org/10.1016/j.crmeth.2026.101306

To cite a specific version of the software as well, use
`Kriel, J. SMINT - Spatial Multi-Omics Integration Toolkit (Version 0.2.0)
[Computer software]. https://github.com/JurgenKriel/SMINT`.

When you use a specific method, please also cite the tools SMINT builds on:

- **Cellpose** for segmentation —
  [cellpose.org](https://www.cellpose.org/) lists the papers for Cellpose 3
  and Cellpose-SAM (Cellpose 4).
- **STalign** for sequential-section LDDMM registration —
  [github.com/JEFworks-Lab/STalign](https://github.com/JEFworks-Lab/STalign).
