# Citation

If SMINT contributes to your research, please cite the software. The citation
metadata lives in
[`CITATION.cff`](https://github.com/JurgenKriel/SMINT/blob/main/CITATION.cff)
in the repository, so GitHub's **Cite this repository** button (in the
sidebar of the repository page) gives you APA and BibTeX directly.

=== "BibTeX"

    ```bibtex
    @software{kriel_smint,
      author  = {Kriel, Jurgen},
      title   = {{SMINT} - Spatial Multi-Omics Integration Toolkit},
      version = {0.1.0},
      url     = {https://github.com/JurgenKriel/SMINT},
      license = {MIT}
    }
    ```

=== "APA"

    Kriel, J. *SMINT - Spatial Multi-Omics Integration Toolkit* (Version 0.1.0)
    [Computer software]. https://github.com/JurgenKriel/SMINT

When you use a specific method, please also cite the tools SMINT builds on:

- **Cellpose** for segmentation —
  [cellpose.org](https://www.cellpose.org/) lists the papers for Cellpose 3
  and Cellpose-SAM (Cellpose 4).
- **STalign** for sequential-section LDDMM registration —
  [github.com/JEFworks-Lab/STalign](https://github.com/JEFworks-Lab/STalign).
