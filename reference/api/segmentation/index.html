    Segmentation API¶

    Cell and nucleus segmentation for whole-slide images with Cellpose 3 or 4, importable from smint.segmentation. There are two pipelines; pick one by image size and hardware:

    Pipeline Runs on Tiles Boundary cells Entry point
    Distributed Dask workers: local CPUs/GPUs or SLURM Overlapping Stitched and reconciled run_distributed_segmentation
    Single process One process, one GPU or CPU Non-overlapping Split at tile edges process_large_image

    Both write outline CSVs in pixel coordinates of the full image; see Data formats. Every model load and eval call goes through the Cellpose compatibility layer, so the same code runs on Cellpose 3 and 4.

    flowchart LR
    A[OME-TIFF / OME-Zarr] --> B[generate_tiles]
    B --> C[segment_tile<br/>on each worker]
    C -->|core region| Z[cells.zarr / nuclei.zarr]
    C -->|outlines of expanded tile| D[stitch_and_reconcile]
    D --> E[cells / nuclei<br/>outlines + summary CSVs]

    Distributed segmentation¶

    The image is cut into core tiles; each worker segments its tile expanded by an overlap margin, writes the core region into shared Zarr label masks and returns outlines of every object it saw whole. The coordinator then stitches duplicate outlines and reconciles cells with nuclei. Needs pip install 'smint[distributed]' and Cellpose.

    from smint.segmentation import run_distributed_segmentation

result = run_distributed_segmentation(
    "slide.ome.tif", "results/dist", config_path="my_config.yaml",
    backend="slurm", n_workers=4, slurm={"gpu_type": "A30"},
)
print(result["total_cells"], result["total_nuclei"], result["failed_tiles"])

    Stitching and reconciliation¶

    smint.segmentation.stitching is a Python port of an R stitching workflow (stitching.Rmd). It works on Shapely polygons, so you can also use it on outlines from any other tiled segmentation. Stage 1 runs per object type, stage 2 on cells and nuclei together:

    flowchart LR
    subgraph S1[Stage 1: stitch_polygons]
        M[merge<br/>overlap > merge_threshold] --> T[trim<br/>overlap < trim_threshold] --> R[remove smaller<br/>overlap >= trim_threshold]
    end
    S1 --> F[filter_by_nuclei]
    F --> S2[Stage 2: reconcile_cells_and_nuclei<br/>one nucleus per cell]
    from smint.segmentation.stitching import (
    polygons_from_outlines, stitch_polygons, reconcile_cells_and_nuclei,
)

# cell_outlines / nucleus_outlines: lists of {"x_coords": array, "y_coords": array}
nuclei = stitch_polygons(polygons_from_outlines(nucleus_outlines))
cells = stitch_polygons(polygons_from_outlines(cell_outlines))
cells, nuclei, nucleus_cell = reconcile_cells_and_nuclei(cells, nuclei)

    *_outlines are lists of dicts with x_coords / y_coords arrays, as segment_tile and get_cell_outlines return them.

    smint.segmentation.stitching.stitch_polygons ¶

    stitch_polygons(geoms, merge_threshold=0.5, trim_threshold=0.25, max_merge_rounds=10, min_overlap_area=1.0)

    Resolve duplicate and colliding polygons from overlapping tiles.

    Runs three phases in order, each on the result of the last. The maximum overlap of a pair is their intersection area divided by the smaller polygon's area.

    1. Merge: union pairs whose maximum overlap exceeds merge_threshold (the same object seen by two tiles), repeating until nothing merges.
    2. Trim: for pairs below trim_threshold (a minor collision), remove the overlap from both.
    3. Remove: for pairs at or above trim_threshold, drop the smaller polygon.

    Parameters:

    Name Type Description Default
    geoms sequence

    Shapely polygons.

    		 required
    merge_threshold float

    Merge pairs whose maximum overlap exceeds this.

    		 0.5
    trim_threshold float

    Trim pairs below this; remove the smaller of pairs at or above it (and not merged).

    		 0.25
    max_merge_rounds int

    Cap on merge iterations.

    		 10
    min_overlap_area float

    Ignore intersections smaller than this.

    		 1.0

    Returns:

    Type Description
    ndarray

    Stitched polygons.

    smint.segmentation.stitching.reconcile_cells_and_nuclei ¶

    reconcile_cells_and_nuclei(cells, nuclei, min_overlap_area=1.0, min_nucleus_fraction=0.1, split_keep_fraction_2=0.4, split_keep_fraction_3plus=0.3)

    Make cells and nuclei consistent and assign each nucleus to one cell.

    Steps, following stitching.Rmd:

    1. Drop cells touching no nucleus, and cells whose only nucleus overlaps them by less than min_nucleus_fraction of the nucleus.
    2. Grow a cell over a nucleus that touches only that cell and is more than half (but not fully) inside it.
    3. Split nuclei straddling several cells into per-cell pieces. A piece is kept if it holds at least 50% of the nucleus, or -- for a cell with no other nucleus -- at least split_keep_fraction_2 (nucleus in 2 cells) or split_keep_fraction_3plus (3+ cells); a single-nucleus cell holding less than that is dropped.
    4. Remove identical, contained and mostly-covered duplicates among cells and among nuclei; cut remaining overlaps out of the larger object.
    5. Assign: a nucleus more than half inside a cell is absorbed into it; one less than half inside is cut out of the cell (and the cell out of it). Nuclei left without a cell become nucleus-only cells; nuclei still straddling a boundary are dropped; cells with no nucleus are dropped.

    Parameters:

    Name Type Description Default
    cells sequence

    Stitched cell polygons.

    		 required
    nuclei sequence

    Stitched nucleus polygons.

    		 required
    min_overlap_area float

    Ignore intersections smaller than this.

    		 1.0
    min_nucleus_fraction float

    Step 1 threshold.

    		 0.1
    split_keep_fraction_2 float

    Step 3 threshold, nucleus in 2 cells.

    		 0.4
    split_keep_fraction_3plus float

    Step 3 threshold, nucleus in 3+ cells.

    		 0.3

    Returns:

    Type Description
    tuple

    (cells, nuclei, nucleus_cell) where nucleus_cell[k] is the index into cells of the cell containing nucleus k.

    Single-process segmentation¶

    Segments the image chunk by chunk in one process, with no overlap and no stitching, so a cell crossing a chunk edge is reported once per chunk. Use it for images that fit in memory on one machine, or as the fallback when Dask is not available.

    smint.segmentation.process_large_image ¶

    Segment cells and nuclei in a large TIFF, chunk by chunk, in one process.

    The image is read whole with tifffile and reduced to (C, Y, X); each non-overlapping chunk is segmented with the cell model and the nuclei model. There is no overlap and no stitching, so an object crossing a chunk edge is reported once per chunk; use run_distributed_segmentation when that matters.

The same applies to nuclei_model_path, which defaults to "nuclei" (Cellpose 3 only; Cellpose 4 substitutes cpsam).

    Cellpose 3 and 4 compatibility¶

    Cellpose 4 ships a single model (Cellpose-SAM, cpsam), ignores model_type and ignores channels. These helpers make a model name and a Cellpose 3 style channel pair behave the same on both versions.

    channels Cellpose sees
    [0, 0] the first channel, greyscale
    [2, 1] channel index 1 as the cytoplasm, channel index 0 as the nucleus
    [1, 0] channel index 0 alone

    Indices are 1-based into the channel axis; 0 means "none".
