    From registered tables to one per-cell table¶

    Registration is not the end of the SMINT workflow. Once spatial metabolomics (SM) pixels sit in the spatial transcriptomics (ST) coordinate frame, every ST cell can be given the metabolite signal measured around it. The result is one table with a row per cell: its position, its transcripts and its metabolites.

    This tutorial does that join in Python on the Sample 2 output of Tutorial 3. It mirrors the R template integration/metabolomics_integration.R (see R integration): draw a 20 µm circle around each ST cell centroid, collect the SM pixels that fall inside it, and average each m/z column over those pixels.

    You need: the output of Tutorial 3, registered/sample2_sm_transformed.csv (run Tutorial 3 first, from the same folder), and the SMINT tutorial data. Runs in seconds on a laptop; no GPU, Cellpose or STalign needed.

    Download this notebook: 05_integration.ipynb

    What the tutorial data holds. The shipped Sample 2 files are de-identified: ST cell coordinates only (no gene counts) and a random quarter of the MALDI pixels, coordinates only (no m/z intensities). The join below is the same one you run on a full export; here the per-cell value it can show is how many SM pixels each cell received. On your own data the same code averages every m/z column.

    2. Join SM pixels to cells within 20 µm¶

    cKDTree.query_ball_point returns, for every ST cell, the indices of the SM pixels within the radius. That is the Python equivalent of st_join(st_buffer(st_centroid(cells), 20), sm_points) in the R template. Flatten it into a long table of (cell, pixel) pairs:

    In [4]:
    Copied! 
    neighbours = cKDTree(sm_xy).query_ball_point(st_xy, r=RADIUS)
n_pixels = np.array([len(n) for n in neighbours])
pair_cell = np.repeat(np.arange(len(st)), n_pixels)
pair_pixel = np.concatenate([np.asarray(n, dtype=int) for n in neighbours])

print(f"{len(pair_cell):,} (cell, SM pixel) pairs")
print(f"{(n_pixels > 0).mean():.0%} of ST cells have at least one SM pixel within {RADIUS:.0f} µm")
print(f"median SM pixels per covered cell: {np.median(n_pixels[n_pixels > 0]):.0f}")

    A pixel can count towards several neighbouring cells, exactly as in the R template: each cell gets the average of the metabolite signal around it. Cells outside the MALDI-imaged area get no pixels; keep them (with missing metabolite values) or drop them, depending on your analysis.

    3. Build the per-cell table¶

    Average every m/z column over each cell's pixels and add the pixel count and the distance to the nearest SM pixel as quality columns:

    In [5]:
    Copied! 
    def per_cell_metabolites(sm, pair_cell, pair_pixel, mz_cols, n_cells):
    """Mean of each m/z column over the SM pixels joined to each cell."""
    joined = sm.iloc[pair_pixel][mz_cols].assign(_cell=pair_cell)
    means = joined.groupby("_cell").mean()
    return means.reindex(range(n_cells))      # cells without pixels -> NaN


nearest_um, _ = cKDTree(sm_xy).query(st_xy)
cells = st.assign(
    n_sm_pixels=n_pixels,
    nearest_sm_um=nearest_um.round(1),
)
metabolites = per_cell_metabolites(sm, pair_cell, pair_pixel, mz_cols, len(st))
cells = pd.concat([cells, metabolites.set_index(cells.index)], axis=1)

cells.to_csv("integrated/sample2_cells_with_sm.csv", index=False)

    With a full export, cells has one more column per m/z value: the mean abundance around that cell. Add the transcripts by joining the Xenium cell-by-gene matrix on the cell ID (for example cell_feature_matrix read with scanpy.read_10x_h5, or the counts in your Seurat or SpatialExperiment object), and you have the cell × gene × metabolite table the R template saves as a SpatialExperiment.

    The SM pixels sit on a 10 µm grid, so a 20 µm circle can hold up to about 12 of them (π · 20² / 10²) on a full export; the tutorial file keeps a random quarter, hence the median of 2 here. Cells at the edge of the MALDI-imaged area get fewer pixels, and cells outside it none: filter on n_sm_pixels (for example, keep cells with at least half the typical count) before you compare metabolite levels between cells.
